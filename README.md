# Nougaminal

**Nougaminal** is a modern Terminal Emulator for Android, written in Kotlin and Jetpack Compose.

## Features
- Native UI powered by Jetpack Compose.
- Powered by Termux's native PTY (terminal-emulator) and view layers.
